# Kiwis Labs

Tools we wished existed, so we built them.

## Tools

| Tool | What it does |
|---|---|
| [claude-notifier](https://github.com/kiwis-labs/claude-notifier) | macOS notifications for Claude Code when a turn ends or it needs your input. Click one to jump back to the terminal. |

## Install with Homebrew

Every tool installs from one tap.

Let your coding agent do it. Paste this, with the tool name filled in:

```text
Install <tool> for me from https://github.com/kiwis-labs/homebrew-tap:
run `brew tap kiwis-labs/tap`, `brew trust kiwis-labs/tap` and `brew install <tool>`.
Then follow the setup step brew prints after the install, and tell me what it did.
```

Or run it yourself:

```bash
brew tap kiwis-labs/tap
brew trust kiwis-labs/tap
brew install <tool>
```

Each tool's README covers any setup after the install.
